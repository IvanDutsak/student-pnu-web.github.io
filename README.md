# Student PNU Web Platform 🎓

Інтерактивна веб-платформа для зручного перегляду розкладу, збереження обраних пар, перевірки рейтингу та відстеження змін у розкладі Прикарпатського національного університету імені Василя Стефаника.

## 📋 Опис
**Student PNU Web** — це сучасний, швидкий та адаптивний веб-застосунок для студентів. Він дозволяє комфортно працювати з університетськими даними як на комп'ютері, так і на мобільному телефоні. Проєкт працює повністю клієнтськи (без бекенду) і оновлюється автоматично за допомогою скрипта-монітора.

- 📅 **Сучасний розклад** — зручний перегляд пар по днях з можливістю пошуку по групах та викладачах.
- ⭐ **Збережені розклади** — можливість зберегти свій розклад для швидкого доступу (працює офлайн через LocalStorage).
- 🔔 **Зміни в розкладі** — детальний перегляд "Було / Стало" зі зручною фільтрацією (які пари додали, а які скасували).
- 🏆 **Рейтинговий бал** — вбудований калькулятор для розрахунку власного рейтингу.
- 🌙 **Темна тема** — сучасний дизайн з повноцінною підтримкою світлої/темної теми.

---

## 🛠️ Технології
- **HTML5** — структура та семантика
- **CSS3** — стилізація з використанням CSS-змінних, Flexbox/Grid, анімацій та адаптивної верстки
- **JavaScript (Vanilla)** — уся бізнес-логіка, робота з DOM, фільтрація, LocalStorage
- **FontAwesome** — векторні іконки
- **GitHub Pages** — безкоштовний та швидкий хостинг
- **JSON Data** — використання статичних файлів `schedule_data.js` та `schedule_changes.json`, що генеруються автоматично

## 📁 Структура проєкту
```
student-pnu-web.github.io/
├── index.html                   # Головна сторінка
├── schedule_new.html            # Сторінка перегляду розкладу
├── schedule-changes.html        # Детальна історія змін розкладу
├── saved_new.html               # Збережені розклади
├── rating_new.html              # Калькулятор рейтингу
├── profile_new.html             # Профіль студента
│
├── schedule_new.css             # Стилі розкладу (навігація, таблиці)
├── schedule-changes.css         # Стилі сторінки змін (diff-view)
├── index.css                    # Головні стилі (Landing page)
│
├── schedule_new.js              # Логіка парсингу та рендеру розкладу
├── schedule-changes.js          # Логіка порівняння змін
├── theme.js                     # Перемикач темної/світлої теми
├── page-info.js                 # Система підказок на сайті
│
├── schedule_data.js             # Згенерований файл з розкладом (АВТОМАТИЧНО)
└── schedule_changes.json        # Файл історії змін (АВТОМАТИЧНО)
```

## 🚀 Як запустити
1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/IvanDutsak/student-pnu-web.github.io.git
   ```

2. **Відкрийте `index.html`** у будь-якому сучасному браузері:
   - Подвійний клік на `index.html`
   - Або використайте `Live Server` у VS Code для комфортної роботи.

> ⚡ **Серверна частина не потрібна** — проєкт працює повністю автономно. Усі дані розкладу статично зберігаються у JSON/JS файлах, які генеруються сусіднім репозиторієм парсера.
